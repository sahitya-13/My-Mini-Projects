## 2.Resume Analyzer & Job Matcher (Python)

### 📌 Description

A smart tool that analyzes resumes and matches them with job descriptions using basic NLP techniques.

### ⚙️ Features

* Supports PDF and text resumes
* Extracts skills using NLP
* Matches resume with job requirements
* Calculates match score (%)
* Suggests missing skills

### 🛠️ Technologies Used

* Python
* NLTK
* PyPDF2

### ▶️ Installation

```bash
pip install nltk PyPDF2
```

### ▶️ Setup (First Time Only)

```python
import nltk
nltk.download('punkt')
nltk.download('stopwords')
```

### ▶️ How to Run

```bash
python resume_analyzer.py
```
